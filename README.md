Name: Prince Jameel G. Doble
Project Title: To-DO-List
Brief Description: A simple to-do list web app built with HTML, CSS, and JavaScript. 
Users can add tasks, mark them as complete, edit them, filter by status (All/Active/Completed), 
and the list is saved in the browser using localStorage so it persists after a refresh.

Reflection:
In your own words, what is the difference between git add and git commit?

git add stages a file, meaning it tells Git "I want this change included 
in my next commit." It doesn't save anything permanently yet, it just 
prepares it. git commit takes everything that's been staged with git add 
and actually saves it as a permanent in the project's history, 
along with a message explaining what was changed. In short, git add 
prepares the changes, and git commit locks them in.
